# Грозный 1994–1996

Браузерная тактика по сети для двух игроков.

## Файлы

- `index.html` — разметка страницы и настройки патчноута (`GAME_REPO` в начале файла)
- `style.css` — оформление
- `js/core.js` — правила: карты, подразделения, бой, бот, сетевые снимки
- `js/gfx.js` — графика: дома, модели техники, частицы, звук
- `js/ui.js` — интерфейс: меню, лобби, отрисовка боя, управление, музыка, повтор

Сборка не нужна: сайт отдаёт эти файлы как есть. Чтобы запустить локально, откройте `index.html` в браузере.
